### 📌 Overview & Market Insight 💡

Welcome to the definitive curated directory of **cloud migration discovery platforms**, **open-source infrastructure assessment tools**, and **application dependency mapping frameworks**. Whether evaluating enterprise commercial platforms (such as *Azure Migrate*, *AWS Application Discovery Service*, *IBM Turbonomic*, and *Cloudamize*) or self-hostable open-source solutions (like *Prophet*, *CloudShift*, *Discovr*, and *xmigrate*), this list provides comprehensive market coverage for migration architects and DevOps engineers. 🚀

> **📈 Sector Market Size & Industry Dynamics:**  
> The global **Cloud Migration & Infrastructure Assessment Market** is estimated at **$21.66 Billion to $330+ Billion (2025-2026)** (depending on broad vs. specialized service definitions) and is expanding at a rapid **20%–28% CAGR**. The market is **moderately fragmented**: hyperscalers (*Microsoft Azure, AWS, Google Cloud*) dominate native zero-cost discovery and baseline planning, while specialized enterprise SaaS platforms (*Cloudamize, Flexera, Device42, CAST*) capture deep multi-cloud topology, legacy static code assessment, and governance workflows.

## 🔓 Open-Source GitHub Projects 🌾

*Sorted by GitHub Stars_Count (Descending)* 🌟

- **[CloudShift (oslabs-beta)](https://github.com/oslabs-beta/CloudShift)** [![Stars](https://img.shields.io/github/stars/oslabs-beta/CloudShift?style=social&color=white)](https://github.com/oslabs-beta/CloudShift/stargazers) 📦  
  **Secure object storage migration tool for multi-cloud environments**, open-source. **JavaScript-based** (33.9 MB). **Core capabilities**: Automates secure transfer and validation of S3-compatible object storage data between AWS, GCP, and Azure during cloud migration.

- **[Prophet (Cloud-Discovery)](https://github.com/Cloud-Discovery/prophet)** [![Stars](https://img.shields.io/github/stars/Cloud-Discovery/prophet?style=social&color=white)](https://github.com/Cloud-Discovery/prophet/stargazers) 🔍  
  **Automated resource collection, analysis, and management toolset for cloud migration and disaster recovery**, open-source. **CLI & Web UI**. **Core capabilities**: Multi-protocol collection (**Nmap, Ansible, WMI, VMware API**), automatic data masking for sensitive credentials, application topology canvas, and containerized Docker Compose deployment.

- **[machine_stats (tidalmigrations)](https://github.com/tidalmigrations/machine_stats)** [![Stars](https://img.shields.io/github/stars/tidalmigrations/machine_stats?style=social&color=white)](https://github.com/tidalmigrations/machine_stats/stargazers) 📊  
  **Lightweight server stats collector for cloud assessment**, open-source. **Ruby-based** (16.4 MB). **Core capabilities**: Quickly gathers RAM, CPU, disk specs, and OS details across Linux and Windows environments without installing persistent agents.

- **[AIFORCE Discovery Agent (CryptoYogiLLC)](https://github.com/CryptoYogiLLC/aiforce-discovery-agent)** [![Stars](https://img.shields.io/github/stars/CryptoYogiLLC/aiforce-discovery-agent?style=social&color=white)](https://github.com/CryptoYogiLLC/aiforce-discovery-agent/stargazers) 🤖  
  **Microservices-based discovery agent for application modernization**, open-source. **Docker Compose architecture**. **Core capabilities**: 6 collector profiles (**Network Scanner, Code Analyzer, Database Inspector, Infra Probe, Processor, Gateway**) to uncover technical debt and PII prior to migration.

- **[Discovr (Naman1997)](https://github.com/Naman1997/discovr)** [![Stars](https://img.shields.io/github/stars/Naman1997/discovr?style=social&color=white)](https://github.com/Naman1997/discovr/stargazers) 🎯  
  **Portable asset discovery CLI for on-premise and cloud infrastructure**, open-source. **Go single binary**. **Core capabilities**: Active/passive network ARP/ICMP scanning, Nmap wrapper, interactive TUI, and multi-cloud inventory discovery for AWS, Azure, and GCP.

- **[xmigrate (xmigrate)](https://github.com/xmigrate/xmigrate)** [![Stars](https://img.shields.io/github/stars/xmigrate/xmigrate?style=social&color=white)](https://github.com/xmigrate/xmigrate/stargazers) 🚀  
  **Open-source cloud migration execution engine**, open-source. **Python-based**. **Core capabilities**: Automated discovery of target environment specifications, automated cloud network creation, and server image conversion for DC-to-cloud and cloud-to-cloud migrations.

- **[migrationcenter-utils (GoogleCloudPlatform)](https://github.com/GoogleCloudPlatform/migrationcenter-utils)** [![Stars](https://img.shields.io/github/stars/GoogleCloudPlatform/migrationcenter-utils?style=social&color=white)](https://github.com/GoogleCloudPlatform/migrationcenter-utils/stargazers) 🛠️  
  **Utilities and assessment scripts for Google Cloud Migration Center**, open-source. **Python & Shell**. **Core capabilities**: Helper utilities including `codmod` for AI-assisted code assessment and data importers for BigQuery and Google Sheets.

- **[Azure-Migrate (wimmatthyssen)](https://github.com/wimmatthyssen/Azure-Migrate)** [![Stars](https://img.shields.io/github/stars/wimmatthyssen/Azure-Migrate?style=social&color=white)](https://github.com/wimmatthyssen/Azure-Migrate/stargazers) ⚡  
  **PowerShell automation suite for Azure Migrate assessment & deployment**, open-source. **PowerShell**. **Core capabilities**: Automates appliance registration, assessment group creation, and reporting for enterprise Azure migration projects.

- **[goto_cloud (jdepoix)](https://github.com/jdepoix/goto_cloud)** [![Stars](https://img.shields.io/github/stars/jdepoix/goto_cloud?style=social&color=white)](https://github.com/jdepoix/goto_cloud/stargazers) 🔧  
  **Automated server infrastructure cloud migration script**, open-source. **Python-based**. **Core capabilities**: Streamlined server cloning and configuration translation from on-premise environments into cloud instances.

- **[apigee-migration-assessment-tool (apigee)](https://github.com/apigee/apigee-migration-assessment-tool)** [![Stars](https://img.shields.io/github/stars/apigee/apigee-migration-assessment-tool?style=social&color=white)](https://github.com/apigee/apigee-migration-assessment-tool/stargazers) 🔌  
  **Specialized API management migration assessment tool**, open-source. **Go-based**. **Core capabilities**: Scans Apigee Edge/Hybrid proxy configurations and generates compatibility reports for Apigee X cloud migrations.

## ⚠️ Disclaimer ℹ️

- This is a **community-curated** directory — not exhaustive and not an endorsement of any vendor. ℹ️
- **AWS Application Discovery Service and Migration Evaluator are free** for discovery and baseline assessment — you only pay for underlying S3 storage and Athena queries used to analyze exported metrics. **Azure Migrate is free** for discovery, sizing assessments, and planning. 🔷
- **Cloudamize has delivered 1000+ enterprise assessments** with **70-80% average reduction in planning time** and **48% average cost savings**. 📊
- **Open-source discovery tools require self-hosting & setup** — **Prophet requires Docker Compose deployment**; **AIFORCE requires 4GB RAM minimum**; **Discovr requires Go execution or pre-compiled binary**. Always validate discovery scans with a proof-of-concept before committing to enterprise cutover timelines. 🔍
